# GamingTube

**GamingTube** is a full-featured Django web application that serves as a directory platform for **gaming YouTube channels**, videos, and the games they cover.

Users can discover and browse gaming content, watch embedded YouTube videos, read and leave reviews. Registered channel owners can log in and manage their own channels (add, edit, and delete) with image uploads.

---

### Key Features
- Browse channels, games, and videos
- User registration, login, and logout system
- Channel ownership – only the owner can edit or delete their channel
- Image uploads (banners, thumbnails, game covers)
- YouTube video embedding on video detail pages
- Review and rating system for channels
- Responsive, modern UI using Bootstrap 5
- Full use of **Class-Based Views** (`ListView`, `DetailView`, `CreateView`, `UpdateView`)

---

### Apps
- `pages` – Home, About, Contact
- `channels` – Core channel management
- `games` – Game database and relationships
- `videos` – Video management and YouTube integration
- `reviews` – User reviews and ratings
- `accounts` – User authentication
